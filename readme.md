Nessa pasta que fazemos a consulta da API Offline disponibilizada pelo professor.
Explicaçação estrutura:

1 VENV: Ambiente virtual para instalar as dependências necessárias

2 GitIgnore: Evita enviar arquivos que não devem ser enviados ao repositorio

3 consumidor_api: Pega a API local e os dados requisitados e faz o tratamento

4 frontend: Apresenta os dados tratados em uma interface mais visual

5 Requirements.txt: Apresenta as dependencias necessárias para o funcionamento do sistema
